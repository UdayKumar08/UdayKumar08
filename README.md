# Hi, I'm Uday

I'm an AI engineer based in London, building production multi-agent systems for regulated banking and retail clients. Most of my days go into designing retrieval pipelines, orchestrating agents, and making sure the whole thing is observable, safe, and cheap enough to run at scale. My systems have handled over 10,000 requests a day, and careful engineering around caching, routing, and model choice has cut API costs by 38 percent, while production RAG pipelines on AWS have held 99.7 percent uptime.

I currently work as an AI Engineer at SupraCloud. Before that I was a Machine Learning Engineer at Tata Consultancy Services, where I built game content generation and recommendation systems for EA Sports, and a Data Scientist at HCL Technologies. I hold an MSc in Data Science from the University of Essex, where my project looked at stock market prediction with LSTM and GRU models. I speak English and French.

## What I work with

My core stack is Python, FastAPI, LangChain, and LangGraph, with RAG pipelines backed by Pinecone and FAISS. I deploy on Azure and AWS using Docker and GitHub Actions, and I trace and evaluate LLM behaviour with Langfuse. I also write TypeScript and Node.js backend services, have built Slack and Microsoft Teams applications, and have deployed self-hosted open weight models when a project needed to keep data in house. Cursor and Claude Code are part of my daily workflow.

## What I'm building

I keep a few personal projects going alongside client work. The Banking AI Agent is a prototype for tiered customer support that combines input safety checks, intent classification, routing, RAG retrieval, ReAct style tool use, output safety, and PII handling, all running locally through Docker Compose with Terraform configs for AWS ECS. MultiMind Agent is my sandbox for multi-agent coordination patterns. EnergyOps AI is a multi-tenant energy operations platform built with Next.js, FastAPI, LangGraph, MCP, and Azure, which I'm developing step by step through small, tested pull requests.
